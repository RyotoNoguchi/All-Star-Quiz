# 通常問題の判定

常駐ワーカーはclosingの通常問題を、部屋のトランザクション内で一度だけ判定します。受付済み回答は先に確定され、問題のコピーから計算された正誤を利用します。

- 不正解はwrong、回答なしはtimeoutで脱落
- 正解者が2人以上なら、回答時間が最も長い1人だけをslowestで脱落
- 回答時間が同じなら受付連番が最も大きい人をslowestにする
- 正解者が1人なら生存させ、次問へ進む
- 正解者0人なら全員脱落として終了する
- 判定前の退出者と以前の問題で脱落した人は速度比較から除外する

生存状態・脱落理由・QuestionResult・確定時刻を同じトランザクションで保存します。繰り返し実行しても結果を再計算しません。QuestionResultには正解・解説・問題内の回答・判定後の公開参加者情報を記録し、セッションやユーザーIDは含めません。原問題の編集も保存済みのコピーや結果に影響しません。

通常問題の判定後、生存者が残ればresults、0人ならfinished/all_eliminatedです。結果発表後に最後の生存者が退出した場合も終了し、発表済み結果の内容は書き換えません。中止が先に確定した場合は判定結果を作らず、正解を公開しません。
