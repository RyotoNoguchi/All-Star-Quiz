# 問題管理API

`questions.create/get/list/update/delete` は管理者セッション必須です。一覧はカテゴリ、offset、limit（最大100）を指定できます。更新・削除には取得時のversionを送り、競合時は再取得します。削除は非表示化で、既存ゲームとの関連を保持します。

問題文、A〜Dの文字列、正解、normal/final、カテゴリ、解説を保存します。制限時間はゲーム契約に従い10秒です。画像は `choiceImages: { A?: { url, alt }, ... }` でHTTPS URLと代替テキストを保持します。文字列の選択肢は画像の有無にかかわらず必須です。画像アップロード・表示先の管理画面はIssue #21で実装します。このAPIはURL先を取得しません。

`questions.prepareGame({ code, count, category? })` は待機中の部屋のホストのみ使用できます。通常問題を重複なくランダム選択し、最後に最終問題を1問配置します。countは最終問題を含め1〜50です。不足時は既存セットを変更せずエラーにします。

部屋の行ロック内でホスト・有効期限・フェーズを再確認し、問題のコピーをGameQuestion.snapshotに保存します。元問題の編集・削除は保存済みセットに影響しません。返却値は件数とゲームversionのみで、参加者でもあるホストに将来の問題・正解を公開しません。ゲーム進行はこのsnapshotを使用し、公開時には許可されたフィールドだけを取り出します。
