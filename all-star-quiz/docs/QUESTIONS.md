# 問題管理API

`questions.create/get/list/update/delete` は管理者セッション必須です。一覧はカテゴリ、offset、limit（最大100）を指定できます。更新・削除には取得時のversionを送り、競合時は再取得します。削除は非表示化で、既存ゲームとの関連を保持します。

問題文、A〜Dの文字列、正解、normal/final、カテゴリ、解説を保存します。制限時間はゲーム契約に従い10秒です。画像は `choiceImages: { A?: { url, alt }, ... }` でHTTPS URLまたは `/api/question-images/UUID` と代替テキストを保持します。文字列の選択肢は画像の有無にかかわらず必須です。管理画面 `/admin` で一覧・カテゴリ絞り込み・追加・編集・削除確認・出題プレビューを利用できます。このAPIはURL先を取得しません。

`questions.prepareGame({ code, count, category? })` は待機中の部屋のホストのみ使用できます。通常問題を重複なくランダム選択し、最後に最終問題を1問配置します。countは最終問題を含め1〜50です。不足時は既存セットを変更せずエラーにします。

部屋の行ロック内でホスト・有効期限・フェーズを再確認し、問題のコピーをGameQuestion.snapshotに保存します。元問題の編集・削除は保存済みセットに影響しません。返却値は件数とゲームversionのみで、参加者でもあるホストに将来の問題・正解を公開しません。ゲーム進行はこのsnapshotを使用し、公開時には許可されたフィールドだけを取り出します。

## 画像登録

管理者だけが同一オリジンの `POST /api/question-images` にファイルを登録できます。読み取り中に2MBで制限し、実データをデコードしてPNG・JPEG・WebPの静止画、縦横4096ピクセル以下を検証します。WebPに再エンコードしてメタデータを除去し、PostgreSQLに保存します。SVGやアニメーションは登録できません。

画像の取得は管理者、または現在その画像を含む問題が出題されている有効な部屋の参加者に限ります。将来の問題・退出済み参加者への取得を拒否し、共有キャッシュには保存しません。元問題を削除しても保存済みセットの参照を壊さないよう画像を保持します。外部HTTPS URLは従来どおり参照専用で、サーバーから取得しません。サイズ・形式の保証が必要な画像はファイル登録を使用してください。

編集の競合時は入力を保持し、一覧を再取得してから編集し直します。削除は非表示化であり、開始済み／準備済みゲームの問題コピーを変更しません。
