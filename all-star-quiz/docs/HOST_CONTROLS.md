# ホストの進行操作

参加画面の下部に現在のホスト専用の操作欄を表示します。問題数（最終問題を含む1〜50問）と任意のカテゴリを指定し、「問題セットを準備する」で通常問題と最後の最終問題を選びます。問題不足は画面に表示し、既存セットを変更しません。2人以上の参加と準備済みセットがあると開始できます。

回答は10秒または全生存者の回答で自動的に締め切ります。結果画面で正解・脱落理由を確認し、「次の問題へ」で進めます。回答受付中・締切処理中は次問へ進めません。「ゲームを終了・中止」は確認後に中止結果を確定します。

処理中、接続復旧中、応答より古い状態の表示中は操作を止めます。コマンドはUUIDと表示中のversionを送り、通信失敗で成否不明の場合は同じコマンドを再確認します。サーバーの重複処理防止とversion検証で二重進行を防ぎます。権限移譲時には操作欄を外し、新しいホストが進行することを表示します。

参加者・回答数・生存者数はゲームの同期状態から表示します。`host.status` は現在のホストだけに準備済み問題数と接続の有無を返し、5秒ごとに更新します。接続の判定は有効期限内の参加者接続を使い、モニター接続を数えません。切断検出には接続の有効期限と取得間隔の分だけ遅れが生じます。

大画面モニターは操作欄のリンクから別タブで開きます。ホスト自身も参加者として回答し、操作欄には未出題の正解や問題文を表示しません。
