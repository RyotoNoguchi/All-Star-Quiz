# プレイヤーの結果表示

`results` ではサーバーが発表した `lastResult` から本人の回答・正解・正誤・受付までの時間・解説を表示します。生存中の参加者には次問待機を案内し、脱落者には不正解・時間切れ・正解者中の最遅・退出の理由を示します。前の問題で脱落した観戦者の未回答を、新たな時間切れとは扱いません。

次問の開始イベントで全員の画面を自動切替します。脱落者にも問題を表示しますが、回答ボタンは無効のままです。最終結果では保存済みの優勝者・順位・生存問題数・終了理由を表示します。同順位を勝手に連番へ変換せず、サーバーの順位と表示順を維持します。優勝者がいない終了・中止も明示します。

表示元は公開済みの状態だけで、ローカルの回答下書きや効果演出から結果を推測しません。再読み込み・再接続で取得したスナップショットでも同じ内容を表示します。中止時に未発表の問題の正解は表示せず、発表済み結果がある場合のみその結果を残します。
