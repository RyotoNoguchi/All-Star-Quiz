# 出題・回答画面

ホーム画面は `QUESTION_STARTED` を受信すると待合室から現在の問題へ切り替わります。参加者は4択ボタンを押すと直ちに回答を送信します。送信中・回答済み・受付未確認を区別し、確定した回答を変更できません。脱落者は問題を観戦できますが回答できません。

`useGameConnection` は状態取得の往復時間からサーバーとの時刻差を推定します。表示タイマーはその基準と `performance.now()` を使用し、端末の壁時計の変更や再描画で10秒に戻りません。イベントの配信時刻から残り時間を延ばすこともありません。通信遅延による推定誤差はあり、回答の有効期限はサーバーで最終判定します。締切・切断・脱落・送信開始後は新しい回答を無効化します。

`useAnswer` は最初に生成したrequestIdと選択肢を固定し、同期的な送信ガードで二度押しを防止します。未確認のリクエストはゲーム・参加者・問題別にsessionStorageへ保存します。失敗後の再送、ページ再読み込み後の再送でも同じIDを使います。受付済みだが応答だけ失った場合を回復するため、締切後も同じ回答の確認再送は許可します。Cookieセッションとサーバーの重複判定が最終的な権限・受付を決定します。再接続時に本人の受付票が得られれば回答済み表示を復元します。

画像は管理者が登録したHTTPS URLを表示し、CSPの画像ソースもHTTPSに対応しています。取得に失敗した画像は代替表示に切り替え、回答操作を妨げません。画像付き選択肢は代替テキストと文字ラベルを持ち、長い本文・選択肢を折り返します。操作は標準のボタンなのでTabで移動しEnter/Spaceで回答できます。正解・解説・最終問題フラグはこの画面に含めません。結果と脱落理由の詳細表示はIssue #18で接続します。
