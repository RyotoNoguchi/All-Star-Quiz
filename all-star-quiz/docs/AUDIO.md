# モニターの音声

会場で使うホストの大画面モニター1台で「音声を有効にする」を押します。ブラウザーの自動再生制限に合わせ、操作直後にAudioContextを開始します。参加者のスマートフォンでは音を鳴らしません。音量・ミュート・BGMの有無を変更でき、音声が使えなくても全情報は画面に表示します。再読込後は音声オフに戻ります。

正解、不正解、脱落、残り3秒からのカウントダウン、最終問題の鐘、優勝、待機・出題中のBGMをゲーム状態に接続しています。最終問題の鐘は結果発表イベントで一度だけ鳴り、出題時には最終問題であることを知らせません。再接続のスナップショットや、発表後に音を有効にした場合には結果音を再生しません。次問・画面離脱・通信断では不要な音を停止します。

## 再生担当の制御

現在のホストだけが `monitor.audio` でRedis上のゲーム単位の再生権を取得・更新できます。所有者UUIDを比較して更新・解放するため、別タブ・別端末の同時再生を拒否します。権利は10秒で失効し、3秒ごとに更新します。クライアントは要求開始から8秒を再生上限とし、応答の遅延を安全側に扱います。AudioContextのゲインにも期限での消音を予約し、JavaScriptのタイマーが遅れても音量が残らないようにします。Redis停止時は音声を停止し、ゲーム自体は既存の復旧処理に従います。担当画面を閉じた直後に切り替えられない場合は、最大10秒待って有効化してください。

## 音源と利用条件

音源: `src/lib/game-audio.ts` のWeb Audioによるオリジナル合成音。外部の録音、楽曲、効果音ファイルは使用していません。正弦波・三角波の周波数と音量包絡から実行時に生成します。これらの生成音はCC0 1.0として提供し、出典表示なしで利用できます。アプリのソースコード全体へのライセンス変更ではありません。
