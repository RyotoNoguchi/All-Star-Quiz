# 大画面モニター

ホストの参加者画面にある「大画面モニターを開く」から、同じブラウザーの別タブで `/monitor?room=コード` を開きます。現在のホストのCookieセッションを必要とし、URLだけを共有しても閲覧権限は付与されません。別端末への権限移譲・共有リンク発行は含みません。

`monitor.ticket` はホスト認可後、署名対象に `role: monitor` を含む60秒・1回限りの接続チケットを発行します。接続時、各同期要求、各配信、5秒ごとの確認で現在の参加とホスト権限を検証します。ホスト移譲・退出・期限切れ・セッション失効で閲覧を停止します。モニター接続は参加者を追加せず、参加者の接続維持やホスト切断猶予にも影響しません。

モニターの `SYNC_ROOM` とHTTP `monitor.snapshot` は公開スナップショットのみ返します。本人の回答受付票も含めず、正解・解説・最終問題フラグは発表前に出しません。モニターの `SUBMIT_ANSWER` はサーバー側で拒否し、ホスト操作イベントも受け付けません。

プレイヤー画面と共通の接続・状態同期処理を使い、欠落時の再取得、再接続、古い応答の破棄を維持します。待機中の参加者、問題、文字／画像4択、サーバー基準の残り時間、回答数、生存者数を表示します。結果発表・優勝の専用演出はIssue #20で追加します。
